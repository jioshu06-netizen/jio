# 淘宝素材转亚马逊美国站商品套图

## 1. 目标、适用范围与执行原则

以**本次产品**及其权威参考图为唯一事实锚点，将淘宝链接、白底图、详情页截图、规格表、安装说明和本地素材转化为有购买决策价值的**美国英语、1:1、视觉统一**的亚马逊商品图片。**默认计划8张**；用户指定张数、已有图片或不同SKU要求时，按指令调整。默认不制作A+、长详情页、品牌店铺装修、视频或Listing文案；“详情页”一词不自动等同于A+，根据明确交付目标解释。

本技能**仅使用内置 Image Generation 生成或修改图片**，不调用第三方生图API、外部生图服务、CLI生图或其它图像生成模型。可使用当前环境已有的网页查看、图片查看、文本处理、精确计算及文件管理能力获取资料和整理交付物；这些能力不可被描述成另一种生图服务。若用户要求的精确文字排版、像素级局部修改或桌面文件操作不被当前工具支持，清楚说明限制，尽最大可能完成实际可交付成果；不得虚报已执行。

**作图方式与标志禁令**：所有成品画面及图片修改必须使用内置 Image Generation；不得通过代码绘图、程序合成、脚本叠字或其他绘图工具制作成品。代码只可用于资料整理、数值计算、文件检查与交付管理。生成提示词和逐图验收均须要求画面中不出现任何 Logo、图标、车标、品牌标识、水印、商标、版权文字、受版权保护的角色或图案，以及其他可识别的权利标志；产品、道具、车辆、服装和背景均适用。涉及调料瓶的场景，一律使用无品牌、无标签的透明瓶子，并检查瓶体确实透明。

没有获得明确模型版本信息，不宣称使用某具体图像模型版本。用户已要求生成且资料足够时**直接执行**，不反复请求确认提示词。缺少事实时优先做不依赖该事实的图片；只对会造成实质错误的关键缺口发问，不以猜测补全。

## 2. 指令优先级与参考图角色

优先级依次为：
1. 用户本轮明确要求、禁止事项、数量、SKU和特定产品部位修改；
2. 用户确认的本产品尺寸、结构、材质、安装与包装数据；
3. 用户指定的本产品白底图、实拍图、结构图和说明书；
4. 本产品官方详情页中可辨识的事实；
5. 次级参考资料（评价、竞品、风格模板，仅用于启发和问题发现）。

**产品参考决定产品本身；风格参考只决定构图、配色、光照、信息层次及排版。** 风格参考中的异款产品结构、道具、配件、数值、宣传话术不得迁移。发现两份资料矛盾时记录差异并采用用户最后明确确认的版本；没有确认则避开冲突点，必要时提问。

## 3. 输入资料读取与事实台账

### 3.1 识别产品与SKU

每次接收新资料，先与当前产品核对：外形、用途、结构、材质、透明区域、尺寸、颜色、配件、安装方式、运动机构及SKU。不同产品不得继承旧产品的参数与卖点；同款不同色只改变指定颜色区域，不能顺带改变结构、透明度和配件。建立以下内部台账：

| 字段 | 记录要求 |
| --- | --- |
| 产品身份 | 通用产品名称、用途、产品参考图、型号/SKU |
| 已确认事实 | 材质、规格、承重、配件、安装、颜色、限制，并注明证据来源 |
| 产品不变量 | 结构、比例、零件数、孔位、连接、透明区域、运动路径 |
| 可改项目 | 仅用户授权修改的部位、色彩、环境、光线、图文 |
| SKU差异 | 一行一型号列出区别与适用的图片，禁止串款 |
| 未确认信息 | 具体缺口、可能影响哪些图片、处理状态 |
| 素材映射 | 每张输入图：展示内容、证实事项、可用于哪张输出 |

### 3.2 淘宝链接和本地素材

用户提供淘宝链接时，尽可能查看商品主图、SKU选择、可访问的完整详情页、尺寸表、安装说明、包装清单及款式差异。首屏和缩略图不代替完整详情。若页面受登录、反爬、地区或浏览器工具限制，仅使用当前环境实际可用的页面及用户补充素材，不假称已经打开完整网页或已登录浏览器。买家评价只辅助识别潜在关注点，不作为配置、性能或实验结论的依据。

本地文件夹、截图和模板逐张检查；有图表、长图或小字时放大查看。用户指定的资料库与模板文件夹**只读**，不移动、覆盖或修改原文件。没有权限读取时说明具体缺失，不推断未见内容。

### 3.3 证据级别

将拟用于图片的内容分成：**已验证**（来自明确资料）、**合理场景示意**（不暗示随箱或性能）、**待确认**（不得作为事实宣称）。承重、耐候、防火、防水、认证、测试、安装净空、尺寸、材料牌号、质保等属于需要有依据的事实；没有资料则不编造。对估算值只能在用户允许估算的情况下，明确标为“Estimated”，不得写成制造商实测规格。

## 4. 生成前必须完成的预检

在第一次生图前，简洁输出：
- **产品摘要**：类别、主要SKU、消费者核心问题和3–5个有据卖点；
- **关键不变量**：哪些部位必须保持、哪些局部允许修改；
- **缺口与处理**：缺少的数据将避开、留空、标为待确认，还是必须询问；
- **本套视觉系统**：主色编号、HEX、字体、画布、标题/正文尺寸基准；
- **8张计划**：每张的购买问题、画面内容、英文短文案、参考资料与验收重点。

如果用户只要求局部修改或单张图，不强制输出整套计划；按该张图所需事实执行即可。计划可以在证据不足时调整，但不能自行突破用户指定的张数和禁止事项。

## 5. 智能规划：默认8张

### 5.1 必须覆盖的购买决策

不机械套固定七图：整套优先覆盖**认知产品、真实外形、尺寸/适配、结构或材质、核心功能、操作或安装、真实使用场景、真实状态差异**。根据类目改变次序、分配张数与展示方式，避免相邻图片重复信息。每张围绕一个明确问题；除必须的规格、安装限制外，通常1个短标题＋0–3个短标签。

### 5.2 默认8张推荐槽位（可以按产品类别重排、替换）

| 槽位 | 优先内容 | 目标与限制 |
| --- | --- | --- |
| 01 | 主视觉或现有白底主图 | 首眼识别外形、用途；如果计划用于Amazon MAIN，采用合规白底商品主图，不使用文字/场景/装饰。若用户已有主图且不要求重做，可沿用并计入或不计入8张，以用户口径为准。 |
| 02 | 尺寸及兼容条件 | 准确产品尺寸、适用安装净空或规格表，不把包装尺寸当产品尺寸。 |
| 03 | 核心结构/细节 | 真实材质、做工、固定点、连接结构或透明区特写。 |
| 04 | 第一核心功能 | 以真实动作、状态或操作流程解释购买理由。 |
| 05 | 第二核心功能/安装 | 不重复04；资料不足时替换成可靠的结构或使用细节。 |
| 06 | 纯场景图 | 无文字、无Logo、无图标、无尺寸线；真实环境、比例、安装关系。 |
| 07 | 多场景/配件说明/使用限制 | 根据产品选择最有价值的信息，不做空洞凑图。 |
| 08 | 真实状态对比或决策总结 | 优先同一产品展开/收起、开启/关闭、使用前/后等**有证据**的真实状态；没有真实可比信息时改为安装条件、适配范围或其他未覆盖的重要信息，不制造竞品缺陷。 |

**类目映射建议：**
- 收纳/家具：尺寸与净空、承重（有证据时）、运动路径、收纳容量、不同空间搭配；
- 工具/工业/车库：材料与接口、安装轨道/五金、透明或密封区域、使用状态、环境适用限制；
- 家居装饰：材质纹理、比例参照、不同布置方式、开关/功能状态、真实居家氛围；
- 组合件/多SKU：配置清单、SKU对照、尺寸适配、关键区别，避免一图混合不同款式。

如果用户要求**必须有对比图**，则保留对比槽位；缺真实状态依据时先完成其余图，明确列出对比图阻塞原因和需要的素材，而不编造。默认8张是计划数量，不是允许无事实填充8张的理由。

### 5.3 亚马逊MAIN与营销辅图分离

本Skill中的“第一张”只是展示顺序；只有明确作为Amazon MAIN上传时，才按**当前官方对应类目**的主图要求制作与核验。不可将带场景、标题、图标的营销首图直接宣称为合规MAIN。若用户已有白底主图且不重做，沿用原图；应说明其是否计入8张。涉及实时规范时查阅当前官方资料；无法核验时不得保证合规。

## 7. 按类目选择并锁定字体与视觉规格

优先使用适合英文阅读的字体组合；用户指定字体高于默认推荐：

| 类目/画风 | 标题建议 | 正文、标签、尺寸建议 |
| --- | --- | --- |
| 工业、工具、车库 | Montserrat Bold | Inter Regular |
| 现代家居、收纳、家具 | Montserrat SemiBold | Inter Regular |
| 高级家居、装饰 | Cambria Bold | Arial Regular |
| 其他/不确定 | Montserrat Bold | Arial Regular |

一套确定字体后，不随不同图片切换。标题不拉伸、不倾斜、不随意改变字重。英文主标题通常3–6词，优先精简，不为塞长句在单张大幅缩小字号。正文以自然、简洁的美国英语书写；不使用未经授权的品牌名称或Logo。

**基础画布**：1:1，优先2000×2000 px；若图像工具不支持指定像素，先以其支持的1:1原始输出工作，再按可用能力导出用户指定大小，不能虚称精确像素。设计基准：标题约110px、正文约44px（基于2000px画布），其余字号、边距、线条、圆角、图标笔画一次锁定，必要时在**整套层面**统一调整。画面须保证手机缩略图下标题可读、产品明显。

**字体精度边界**：提示词写明字体不等于实际已验证字体。内置生图若不能精确生成某字体、字号、规格表或标点，应记录残余误差；不得对未验证项声称像素级一致。不得通过代码或其他绘图工具叠字、排版或修图；无法由内置 Image Generation 准确完成时，诚实说明限制。

## 8. 产品还原硬约束

每张图生成前均附本产品权威参考和本张细节参考，明确各自用途；可沿用已验收图作为**视觉风格参考**，但该图不能替代权威产品结构参考。

### 8.1 永不擅自改变

- 结构、外轮廓、厚薄、实际比例、零部件数量、孔位、螺丝、连接点、安装形式；
- 材质、表面反光、透光区、透明度、颜色分区（除用户明确授权修改区域）；
- 滑轨、机械臂、挂钩、拉篮、帘子、铰链等机构的真实连接、运动方向与路径；
- 用户确认的尺寸、参数、SKU及配件；
- 产品与墙、柜、轨道、地面等真实接触关系，不悬空、不穿模、不错误遮挡。

### 8.2 仅在明确允许时修改

场景、相机机位、光影、道具和信息排版可以调整，但不得改变产品身份。换色时明确遮罩对象、颜色HEX/名称及应保留的透明/金属/织物区域；**未被要求的部位保持不变**。道具不得误导用户认为随箱附赠；可选件只有证实可选且画面需要时才标注 `Optional accessory` 等准确说法。

若参考只有单一角度，不能凭空保证背面结构正确；使用可验证机位，或将不可验证的部分隐藏/列为待确认。复杂精密结构不能依赖风格图“脑补”。

## 9. 英文文案、数字与尺寸图

所有出图可见文案为**美国英语**，除非用户另行指定。文案先在文本阶段定稿、拼写复核，再送入生图。禁止虚构性能、最高级、认证、测试数值、保修承诺、医学/杀菌效果、环保绝对承诺、价格促销、评论星级、联系方式、二维码、水印及未经授权标识。防风、防雨、防雪等仅按证据和适用条件表述，不把辅助防护夸大为绝对效果。避免竞品贬低。

尺寸规则：
1. 先提取**原始数值和单位**，核查型号、宽/高/深定义及数据来源。
2. `cm = mm / 10`；`in = mm / 25.4`。使用未四舍五入的原始数值分别换算，默认两种单位均保留1位小数（若精度会造成误导，应调整精度并注明）。
3. 同一标注同时显示 `cm` 与 `in`，如 `120.0 cm / 47.2 in`；确保标注箭头端点实际落在正确边界。
4. 严格区分产品尺寸、安装净空、轨道长度和**包装尺寸**；包装估算只有用户授权后才能注明 `Estimated package size`，不得当作实测。
5. 用户给出规格表时保留完整型号关系、列名、单位、不等号及适用条件；太密时拆成两张或调整套图规划，不能默默漏行、漏列、缩成不可读小字。

**数字与表格分工**：优先在生成前计算并核对准确文本、表格结构和标线语义，再制作视觉；不要要求生图模型自行推算数值。如果存在精确标注能力，优先用其处理数字、表格和尺寸线；否则对渲染后数字进行逐项人工/视觉复核，任何错误不得标为通过。

## 10. 标准单张生成指令结构

每张调用内置 Image Generation 时，组织提示内容为：

1. **任务目标**：序号、图片类型、消费者应理解的唯一主题、1:1画布要求；
2. **产品身份与硬约束**：指定本产品参考图及不可改部位，必要时描述机械连接和实际比例；
3. **参考图分工**：产品图控制结构，样式参考控制设计，场景参考只控制环境/机位；
4. **场景与构图**：真实美式使用环境、构图重心、产品占比、真实灯光与材质，不违背安装关系；
5. **精准文案**：已经核实的英文标题、标签、数字、大小写和标点；纯场景图明确零文字、零图标；
6. **统一视觉令牌**：九色中的选定HEX、基础黑/白、已锁定的标题/正文字体与字号基准、图标、页边距；
7. **负面约束**：无Logo/水印/价格/未经证实配件，不改变产品结构、角度含义、数量、材质、运动路径，不凭空添加标签。

先生成首张需要排版的图并确认其视觉基准，再持续复用作为同套样式参考。需要针对某局部修复时，应优先编辑原图并**只修改指定区域**，不得用重新生成整张图替代局部修改，除非确实无法定向修复。

## 11. 逐图质量验收与失败恢复

### 11.1 每张图片检查表

每张生成后立即与原产品资料和预检台账核对，以下**硬性项任一失败即不得验收**：
- 产品身份、结构、比例、零件数、孔位、连接关系、材质、透明区域正确；
- SKU、颜色、配件、安装条件和动作路径正确，无穿模、悬空或虚构部件；
- 英文拼写、数字、单位换算、标线端点、表格行列和限制条件准确；
- 画布为1:1；纯场景图**完全无文字、图标、标注、Logo**；
- 无违背用户禁止事项、无虚假性能、无未经授权标志。

同时检查**视觉质量项**：商业摄影真实感、自然光照与物理材质、人体和道具比例、明确视觉层次、移动端可读性、标题/字号/字色、统一强调色与边距、不过量图标、每张布局有区分。视觉质量不足应修复，但不得牺牲结构真实性换取美观。

### 11.2 修复策略

每张状态仅为：`planned` → `generated` → `checking` → `passed`；或 `needs_fix` / `blocked`。记录问题类别、位置、依据和操作。

- **第一轮**：定位单个或少数问题，使用原图进行**定向局部修改**，保留其他通过的区域。
- **第二轮**：若仍失败，调整提示描述、参考图选择或构图策略，避免让模型臆造不可见结构；再次验收。
- **两轮后仍失败**：标记 `blocked`，列出具体原因，保留当前最佳候选和参考资料；必要时建议精确排版、用户补图或人工处理。不以不合格图充当验收成品，也不无限循环重试。

如果缺少生成/编辑工具能力或工具失败，明确哪些图片未生成、哪些未通过；禁止仅以提示词代替成图。不能因为图片“看着不错”而跳过数字、结构、事实检查。

### 11.3 整套复核

将全部候选并排缩小查看：主色一致、字体体系一致、标题层级统一、布局具有变化、卖点互补不重复、图片顺序清晰、全部SKU事实正确、纯场景无字。对任何受累图片回到逐张检查流程；通过项才纳入最终合格交付。

## 12. 交付与文件组织

保留内置生图原始输出，不覆盖用户输入、模板或素材。只有当当前环境**确实有桌面写入权限**且用户要求桌面交付时，才在桌面创建下一个未使用的两位数字目录 `01`、`02`、`03`……，跳过已有目录，不覆盖。否则在当前可写工作目录建立唯一目录，并如实说明位置；可提供实际生成的ZIP或文件链接，不能虚构桌面路径。

建议交付结构：

```text
NN/
├── 01_main_or_hero.png
├── 02_dimensions.png
├── 03_details.png
├── 04_feature_01.png
├── 05_feature_02_or_install.png
├── 06_lifestyle_clean.png
├── 07_use_case_or_sku.png
├── 08_comparison_or_decision.png
├── prompts.md
├── product_facts.md
└── qa_report.md
```

真实文件名与智能规划后的内容对应；未通过或未生成项**不得伪装为定稿图片**，可单独放入 `review_required/`（如可用）。用户沿用原有主图时在记录中注明来源、是否计入总数；未获修改授权不覆盖原图。

`product_facts.md` 记录SKU、确认参数、证据、不可变项、缺口；`prompts.md` 记录每张最终提示词和样式锁定值；`qa_report.md` 逐项写入文件名、状态（passed/blocked）、来源图、核验点、修复次数、未解决问题。核验最终图片数量、格式、比例、文件能否打开及压缩包内容；有能力时同时交付整套预览拼图。不能用“全部无误”掩盖生图误差，必须清楚区分**已验证**和**仍待人工确认**。

## 13. 高级商业质感与自然流量转化（默认启用）

### 13.1 商业目标与边界

默认面向新店铺、评论与广告投入有限的美国站商品，服务两段不同任务：
- **搜索结果页：** 合规MAIN主图在真实产品、价格等其他因素共同作用下，帮助买家快速辨识商品、颜色、规格和价值定位；不得承诺提高搜索排名或必然获得曝光。
- **商品详情页：** 辅图在数秒内回答买家是否适用、结构如何、尺寸对不对、如何安装、随箱有什么以及真实使用情境；目标是降低理解门槛与购买顾虑，不虚构转化率或订单增长。

**高级感不是“加更多设计元素”。** 优先真实摄影质感、产品主次、精确比例、自然光照、材质细节、专业留白和少而明确的英文信息。禁止以夸张光效、复杂渐变、虚拟悬浮装置、过度景深或华丽修饰掩盖事实。没有提供售价与定位时不臆称“奢侈品”或特定价格档次。

### 13.2 按产品类别锁定艺术指导（Art Direction）

在第4节预检时先确定一种艺术指导，整套保持一致；不得把同一背景模板机械复用到所有品类。

| 产品类别 | 商业摄影方向 | 材质与场景重点 | 应避免 |
| --- | --- | --- | --- |
| 工业、工具、车库 | 建筑产品摄影；稳重、精确、硬朗，干净的中性灰或真实车间光线 | 真实金属微反射、铝材拉丝、PVC透光及褶皱、轨道水平和安装边界 | 赛博朋克霓虹、油污脏乱、过强轮廓光、虚构工业规模 |
| 现代家具、厨房收纳 | 北美中高端住宅生活方式；自然侧窗光、低饱和中性色、建筑空间纵深 | 木饰面、金属、玻璃、柜体与产品的真实连接和比例 | 大面积假大理石、过度摆件、结构穿模、不真实悬浮 |
| 户外、园艺、庭院 | 真实北美庭院或工作环境；清晰日照、自然材料和可信天气 | 产品尺寸、地面接触、耐候部位的可见设计（不暗示未经证实性能） | 夸张极端天气、虚假耐用测试、摄影棚与户外光线冲突 |
| 装饰、家居软装 | 精品家居目录的编辑摄影；温和对比、材料质感、真实居家氛围 | 织物、玻璃、金属表面的物理真实感和空间尺度 | 不合理奢华陈设、极端模糊、空洞氛围图 |

选色只使用第6节九色板中的一种强调色；真实场景和产品本色自然存在。宁可减少强调色覆盖面积，也不为保持色板而牺牲真实场景。建议强调色主要出现在标题重点、细线、编号或少量信息块，避免整幅色块压住产品。**纯场景图仍然绝对无字、无图标。**

### 13.3 高级感的可检验标准

每张验收时按以下维度做视觉诊断；仅属于内部判断，不把主观分数当成实测数据。

1. **真实与可信**：金属有正确反射，玻璃有合理透射，PVC材质柔顺且透明度符合产品，阴影方向一致；无虚假配件、变形、穿模。
2. **摄影与光照**：光源清楚，明暗层次合理，白平衡统一，无塑料感、脏灰、发光边缘、过曝高光和不合理锐化。
3. **构图与主次**：主体优先、视线明确，场景与标注服务于产品；一张只突出一个购买问题，不堆满箭头、图标和细节窗。
4. **版式与字体**：一致的字体体系、字重、对齐逻辑、字号层级、边距及视觉网格；标题精炼、有呼吸感，避免大段英文说明或字体任意放大缩小。
5. **移动端识别**：以约手机缩略图视角再次检查，产品轮廓、最重要的信息和尺寸单位可识别；不能识别则优先删减内容或拆图，而非盲目放大一切。
6. **场景可信度**：真实美国典型家居/仓库/车库尺度，产品安装位置、物件比例和人的操作姿态正确；不出现与用途不相关的奢华空间。
7. **整套一致且不单调**：一致的商业摄影气质、标题系统、强调色和修图方式；远景、中景、近景、正视、局部可合理变化，不做八张雷同拼贴。

### 13.4 图像信息架构：先解决购买疑虑，再追求画面漂亮

针对8张默认规划，给每张先写一句**买家问题**和一个**可验证的回答**；不能提出真实素材无法回答的问题。优先级参考如下：

- 搜索点击阶段：MAIN突出真实产品外形、准确颜色和比例；主图为符合类目规范的纯白底真实产品展示，不添加标题、场景、装饰或无关道具。
- 初次理解阶段：清楚展示产品在真实环境中的作用，不制造与包装/赠品有关的误解。
- 适配决策阶段：用尺寸/安装净空/SKU差异解决“买回来能不能装、合不合适”。
- 质量判断阶段：真实材质及细节近景，不用无法证实的“顶级”“终身”“100%”等词。
- 功能理解阶段：显示真实开合、移动、安装或操作状态，不推演未被证明的性能。
- 风险消除阶段：根据素材说明限制、所含配件、兼容条件和真实状态差异。

**八张图是默认制作数量，不是保证前台一定显示八张，也不是在每张重复主要卖点。** 根据站点及类目当前展示限制安排上传优先级；若只有部分辅图位置可见，优先保留信息价值最高的图片。自然流量的获取还取决于搜索相关性、标题、价格、供货、配送、评价等因素；本Skill不把“图片精美”等同于自然搜索排名提高。

### 13.5 文字与配色去廉价化规则

- 避免过度使用胶囊形卖点框、泛滥的勾号和箭头、过粗描边、重复三维徽章、无意义光晕、过多渐变、廉价促销海报样式。
- 一般一张不超过1个核心标题、1句简短解释及3个信息要点；规格表和安装警示属于例外。更多信息拆到另一张，而不是压缩成密集小字。
- 主标题采用适合美国消费者的清晰、自然英文，强调具体用途与购买决策，不堆砌关键词；不写空洞的“Premium Quality”“Ultimate Solution”等无证据营销句。
- 优先中性留白、适度材质纹理和真实产品边缘；强烈视觉强调只用于最重要的一个信息。
- 不加入未经授权的品牌或Logo，不套用其他商家的产品图视觉识别，不暗示认证/评分/销量排名。

### 13.6 视觉验收等级与调整顺序

在第11节硬约束之外，对视觉质量采用三级判断：
- `premium_pass`：摄影、材质、构图、字级、场景可信度和移动端可读性均达到本类目的商业图片要求。
- `visual_fix`：事实正确但存在明显廉价化装饰、AI质感、主体不突出、字太密或布局不统一，必须优先定向修复。
- `fact_blocked`：结构、数值、SKU、安装、配件或声明不真实；无论画面多漂亮都不得通过。

修复顺序：**事实错误 → 结构和场景真实性 → 主体与商业摄影质感 → 信息层次与移动端识别 → 细节美化**。保留每张的原图及问题描述，定向修改后检查产品是否意外变化。不要用追求高级感的理由增大生成轮数、牺牲正确性或无限重复审美微调。

### 13.7 交付验收记录追加内容

`qa_report.md` 每张增加：`buyer_question`（购买疑虑）、`art_direction`（本套摄影风格）、`premium_status`、`mobile_readable`、`visual_issue`、`fix_action`。整套验收增加两项：8张在缩略图视角是否有清晰的阅读节奏；有没有重复卖点、无效装饰或可能引起退货的误导信息。

## 14. 完成条件

只有满足以下条件才能宣称整套完成：
1. 实际成功交付约定数量的独立1:1图片（或明确说明不足）；
2. 每张通过产品、事实、英文、数字和场景硬约束验收；
3. 同套色板、字体体系、信息层次一致，纯场景图零文字；
4. 交付路径和文件真实存在，未覆盖原素材；
5. 说明任何未核实的Amazon当前规则、像素级字体限制及剩余人工复核项。

**底线：真实性优先于视觉夸张，正确产品优先于漂亮构图，已证实信息优先于营销承诺；高级感必须服务于购买决策，不能验证就不声称已验证。**
